## Codebase Patterns
- Predictive models live in `ml/src/draft_oracle/models/` (US-011+). Pattern: pure
  unit-tested primitives (`brier_score`, feature-row builders) + a dataclass result with
  `report_lines()` (ASCII Markdown) and `manifest()` (seed+splits+metrics), + a
  `train_*_from_normalized` that reads `data/normalized/*.parquet` and writes committed
  `artifacts/models/<name>/{report.md,manifest.json}` (both re-included in .gitignore), +
  a `oracle <cmd>` CLI. Splits are strictly temporal (`default_temporal_split`: newest N
  seasons held out for test, next for val, rest train); seed is fixed; misses reported
  honestly (SPEC §7), never forced. Per-game features are built leakage-free in ONE
  chronological pass (snapshot BEFORE folding the current result), reusing team_series Elo.
- STALE PARQUET GOTCHA: the committed `ml/data/normalized/*.parquet` can lag the current
  `normalize.py` schema (e.g. it was missing `shots_against`, which the raw team-games
  archive DOES carry as `shotsAgainstPerGame`). If a model needs a column absent from the
  current parquet, run `uv run oracle normalize --force` to regenerate before training.
  `shotsAgainstPerGame` is per-game (== that game's shots-against). Team save % =
  `1 - GA/shots_against` is the goalie-slot proxy (no per-goalie rows exist in the archive).
- Shutout model (US-012, `models/shutout.py`) mirrors game_win: winner-framed rows (one per
  decided game, label = winner held loser scoreless => `P(shutout | win)`), leakage-free
  chronological pass over `ShutoutTeamState` (season + last-15 team save %, team shutout
  rate, GF/game), LightGBM `monotone_constraints` keep it monotone in goalie quality.
  Headline metric is CALIBRATION (predicted vs observed shutout rate within +/-25%), NOT
  beating base rate — a rare event's constant base rate is a very strong Brier baseline and
  is expected to roughly tie; report both honestly.

- Composed models (US-013 `models/series_sim.py`) COMPOSE the per-game win + shutout
  models, they do not learn per-series. Best-of-7 = exact enumeration over <=2^7 paths
  (recurse over game outcomes, stop at 4 wins, weight by product of per-game probs) -
  deterministic, no seed; seeded Monte-Carlo only cross-checks. Home-ice = 2-2-1-1-1
  `HOME_ICE_PATTERN=("A","A","B","B","A","B","A")` (A=higher seed). E[goalie points] is
  LINEAR: `E[wins]*(WIN_POINTS + (SHUTOUT_POINTS-WIN_POINTS)*P(shutout|win))` == mean of
  `rules.goalie_series_points` (shutout upgrades a win 2->4, never additive); P(shutout|win)
  is venue-independent (winner-framed) so it's ONE scalar/team. Leakage-free composed
  evaluation: filter team_games to seasons BEFORE the held-out set and train sub-models on
  that slice (their `.model` is fit only on what you pass), but build as-of pre-series
  FEATURES from ALL games in one chronological pass (feature computation != training).
  The `series` parquet gives actual winner + length (top_seed_wins+bottom_seed_wins) +
  playoff_round; `series.year == team_games season_id % 10000` (season end year).
- Playoff-round reconstruction (US-014 `models/skater_production.py`): the `series`
  parquet has NO dates, so map each playoff game to a round by pairing its
  order-independent {team_abbrev, opponent_team_abbrev} against
  (top_seed_abbrev, bottom_seed_abbrev) per (season_id). Round START date =
  earliest game_date of that (season, round); it is the EXCLUSIVE as-of cutoff.
  ~18 games/archive don't map (2019-20 bubble round-robin, round 0) - drop them,
  don't crash. Because the cutoff is derived from a round's OWN games, features
  (strictly before cutoff) and labels (that round's games, >= cutoff) never overlap
  regardless of the bubble's scrambled round numbering. Skater production LABEL =
  observed (goals+assists)/GP in that round (rules.player_points weights G,A equally).
- Cold-case / shrinkage pattern (reusable for skater-rate models): shrink a model
  estimate toward a position+team prior by credibility `w=n/(n+k)`
  (`shrink_to_prior`); priors (`fit_priors`) are fit on TRAIN rows only so the test
  label never leaks into its own shrinkage target. Players with NO regular-season
  games have no US-009 feature row (inner-joined out); price them from the prior via
  `SkaterProductionModel.project_cold(position, team)` returning
  `(prior, low_confidence=True)` - flagged, never a crash (SPEC 7). Report cold-case
  COUNT for held-out seasons honestly.
- Spearman rank correlation without scipy (`spearman_correlation`): average-rank both
  vectors (ties share their mean rank via `_rankdata`), then Pearson of the ranks;
  return nan for <2 points or zero rank variance. MAE via `mean_absolute_error`.
- Regression sibling of the game_win pattern: choose between a Poisson GLM
  (`PoissonRegressor` on `StandardScaler` features) and `LGBMRegressor(objective=
  "poisson")` on validation MAE; both give non-negative rates (clip raw preds >=0).
- Availability / return-time pattern (US-015, `models/returns.py`): ESPN has NO
  historical injuries (leakage), so return timing is calibrated on ABSENCE SPELLS
  derived from the normalized archive - `derive_absence_spells(skater_games,
  team_games)` finds, per (season, team, player), maximal BOOKENDED runs of missed
  team games (`spells_from_sequence`: only gaps between two appearances count;
  leading=pre-debut, trailing=season-end are excluded). Healthy-scratch guards are
  documented config filters (min_spell=2, min_appearances=20, min_median_toi=600s).
  DESIGN: the empirical spell distribution supplies the return-timing SHAPE; a
  DOCUMENTED status->mean map (`STATUS_MEAN_GAMES` day_to_day=1/out=3/ir=8 games,
  archive has no status label) rescales it for LOCATION. `availability_curve` =
  empirical CDF of the (scaled, optionally games_missed-conditioned) remaining-games
  distribution => P(available game k) is monotone non-decreasing in k by construction
  (threshold k-1 rises). `availability_multiplier` = expected_games/horizon is the
  haircut US-016 multiplies into expected games played. Real archive: 10,470 spells,
  mean 6.19 games, temporal-holdout survival calibration MAE 0.023 (excellent).
- Override precedence pattern (reusable): US-015 added `return_game: int|None` to
  `InjuryOverride` + `load_injury_overrides` (NOT to the injuries parquet columns).
  `project_availability` matches an override to each injury row (espn_id first, then
  normalize_name) and a pinned `return_game` yields a deterministic 0..0,1..1 curve
  that WINS over the model. When adding override-driven fields, extend the dataclass +
  loader only; keep them out of the ingested table to avoid schema churn.
- Composed projection pattern (US-016, `models/projections.py`): round-point
  projections COMPOSE three fitted sub-models, they do not learn a new estimator.
  `project_skater_round(pts_per_game, length_probs, availability_curve=..., seed=...)`
  Monte-Carlos total round points: draw series length L from the simulator's
  `length_probs`, then per game k=1..L draw availability (Bernoulli on the US-015
  curve; scalar `availability` multiplier if no curve) and, when available,
  `Poisson(pts_per_game)` points. Returns mean (`expected_points`) + p10/p50/p90 +
  decomposition (`pts_per_game`, `expected_games`). REPRODUCIBILITY: seed each
  skater's RNG deterministically from `_row_seed(seed, season, round, player)` so a
  projection is reproducible regardless of iteration order. Eval reuses series_sim's
  private helpers `_predict_series`/`_matchup_key`/`reconstruct_series_matchups` to
  get per-team length distributions, and `build_production_dataset` for the leakage-
  free feature+label rows; sub-models train ONLY on non-held-out seasons. Historical
  rounds have NO injury feed (ESPN leakage) => availability=1.0 in backtests; the
  haircut only bites live. Baselines: (a) reg-ppg x `BASELINE_REG_GAMES=5.5`, (b)
  previous-round actual points (round-1 falls back to (a)). Real 2025-2026 holdout:
  model MAE 1.3725 < reg 1.4955 < prev 1.6474; Spearman 0.5941 > 0.5796 > 0.5032 —
  beats BOTH. mypy: np.clip returns Any, assign to a `: np.ndarray` local then return
  it (astype(float) still types Any). CLI `oracle project-skaters`.
