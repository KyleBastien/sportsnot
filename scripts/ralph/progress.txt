- Odds favorite attribution (US-102, `ingest/odds.py`): favorite-only rows go
  through `_favorite_rows_from_games(grouped, source=, resolve_favorite=,
  placeholder_seasons=)`. `resolve_favorite: FavoriteResolver` = `(game_id,
  home_row, away_row) -> "home"|"away"|None`; `None` => emit `_uncovered_row`
  tagged `_unattributed` (covered=False, kept). DEFAULT resolver =
  `_kaggle_favorite_side`, which trusts a favorite ONLY when the two rows carry a
  GENUINE per-team opposite-signed spread (`_favorite_side_from_pair_spreads`:
  `home<0<away`->home). The real Kaggle archive stamps ONE game-level spread on
  BOTH rows (identical), so it attributes NOTHING (honest: Kaggle favorite prices
  are unattributed). GOTCHA: synthetic Kaggle test fixtures (`_kaggle_pair`) use
  opposite-signed spreads (-1.5/+1.5) so they DO attribute -- don't "fix" that.
  ESPN completion (`parse_espn_completion`) is the authoritative path: reads
  `homeTeamOdds.favorite` from `raw/summary/{event_id}.json.gz`
  (`_espn_completion_favorite_sides` + `_pickcenter_favorite_side`; homeTeamOdds
  == the game's home team, no team-id match needed), falling back to ESPN's
  home-relative spread sign when a summary is absent. `devig_favorite_only` floors
  the de-vigged favorite at 0.5 (a -101..-110 favorite must never invert to an
  underdog -- m-5). attrs surfaced: `unattributed_uncovered_rows` (Kaggle),
  alongside US-101's `placeholder_uncovered_rows`.

  `parse_kaggle_extensive` records `frame.attrs["placeholder_uncovered_rows"]`.
  `consolidate_odds` consumes `xval_delta` as a gate (`XVAL_DELTA_THRESHOLD`): when
  covering sources disagree on fav-prob beyond it, `_blank_market_fields` flags the
  consolidated row uncovered (keeps xval_delta/source_count for audit) and counts
  `out.attrs["xval_flagged_rows"]`. Both counts surface via `OddsResult` +
  `oracle odds` CLI. GOTCHA: `_attach_market` (game_win) filters on `home_implied`

  not just set covered=False. pandas `.attrs` survive sort/reset_index/to_parquet on
  the in-memory frame but NOT a parquet round-trip -- read them before writing.
  Run ml checks with `ml/.venv/Scripts/python.exe -m {pytest|ruff check|mypy} src tests`

- IR-stash valuation (US-022, `optimize/ir_value.py`): IR activation is a RETROACTIVE
  same-position swap (SPEC 1) - the stash's whole-round points REPLACE the swapped
  active starter's from the start of the round, so the slot yields
  `max(stash, starter)` (`retroactive_swap_points`), never additive. Marginal
  `stash_value = E[max(X - Y, 0)]`, Y = US-018 replacement level for that position
  (F swaps F, D swaps D). Compose US-015 `ReturnTimeModel.availability_curve(status)`
  (fit spells pre-cutoff, leakage-free; degenerate fallback when no spells) + US-016
  `simulate_round_points`. Verdict "stash" iff stash_value beats the healthy
  replacement-level alt (`healthy_alternative_value`: ppg = baseline/E[len], fully
  available). Cheat sheet gets an IR section via `CheatSheet.ir_section` (pre-rendered
  lines so `vor.py` never imports `ir_value`). `reprice_pool_for_ir` sets injured
  assets' projection to stash_value so the optimizer values IR_F/IR_D realistically;
  `oracle recommend --ir` applies it. Artifact skaters carry
  `ir_stash_ev/ir_stash_value/ir_verdict`.

- VOR / draft-board pattern (US-018, `optimize/vor.py`): replacement level is a PURE
  fn of league size N + roster shape (SPEC 1) — F=(5N+1)-th, D=(3N+1)-th,
  G/team=(N+1)-th; IR adds +1 F/+1 D per manager (6N+1 / 4N+1), never a goalie slot.
  `replacement_level(values, starters)` = sorted-desc[starters] or 0.0 when
  demand>=supply (final round with 2 teams alive, tiny pools) — the "sensible
  handling". VOR = expected_points - replacement, computed per position pool then the
  skater+team rows are UNIONED and sorted by vor desc (tie: projection desc, name).
  A team pick = a whole team's goaltending (projection = `e_goalie_points`, position
  "G", no quantiles). `build_cheatsheet` -> `CheatSheet` with `.summary()` (manifest)
  + `.report_lines()`/`render_cheatsheet_markdown` (ASCII, cp1252-safe). IR flag
  changes BOTH replacement levels AND sheet layout (injured tagged `IR?` vs `OUT`).
  Wired into `projection_artifact`: `ProjectArtifactConfig.managers/ir`, a
  `cheatsheet` field on the result, `cheatsheet.md` written to the artifact dir, and
  `--managers`/`--ir` on `oracle project`.

- Strategy comparison honesty (US-021): use SINGLE-DECISION same-slot framing ("from the
  same slot") — advance to a shared decision slot with a greedy tail, each strategy makes
  ONE pick, finish with an identical greedy-VOR tail; measure final owner value. Do NOT
  run each strategy at EVERY owner pick (recursive tail/policy mismatch: the rollout
  assumes a greedy tail but actual play uses lookahead -> biased, lookahead can lose).
