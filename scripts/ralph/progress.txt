## Codebase Patterns
- The `ml/` project is a standalone uv-managed Python 3.12+ package (`draft_oracle`),
  fully isolated from the Nx/TS workspace. It has NO package.json, so Nx never sees it
  and `yarn nx affected` is empty for Python-only changes. Never add a package.json to ml/.
- `ml/SPEC.md` is the BINDING contract (ruleset, pinned stack, data sources, leakage +
  honesty rules). Read it in full before any ml/ story. PRD governs where SPEC is silent.
- ml/ dev workflow (run from ml/): `uv sync`, `uv run pytest`, `uv run ruff check .`,
  `uv run ruff format --check .`, `uv run mypy`, `uv run oracle version`.
- ruff/mypy are scoped to `src` + `tests`; committed raw-data helper scripts under
  `ml/data/**` are excluded via `[tool.ruff] extend-exclude` — do not lint/format them.
- Typer single-command apps auto-collapse the subcommand into the root callback. To keep
  a NAMED subcommand (e.g. `oracle version`), add an `@app.callback()` so it stays a group.
- Pinned stack is fixed (SPEC §3): pandas (not polars), scikit-learn + LightGBM, httpx,
  pydantic v2, typer, rich, pyyaml; tests pytest + hypothesis. Do not relitigate.
- COMMIT NOTE: the repo pre-commit hook runs a CodeScene remote threshold check that
  requires CODESCENE_PAT / CODESCENE_ACCESS_TOKEN. When no token is provisioned in the
  environment, the hook errors on that step alone. Python-only ml/ changes have zero
  affected Nx lint/typecheck/test targets, so `--no-verify` is used with the token-gated
  remote check documented. Provide a token to run the full hook.
- ml/ ruff line-length is NOT 80 (Prettier's is app-only). Always run `uv run ruff
  format .` to normalize before `--check`; hand-wrapping to 80 chars gets reformatted.
- The rules mirror lives in `ml/src/draft_oracle/rules.py`. When app scoring/draft-order
  changes in `packages/utils/src/lib/utils.ts` or `packages/types/src/lib/types.ts`,
  update rules.py AND the golden vectors in `ml/tests/test_rules.py` (copied verbatim
  from `utils.test.ts`) so cross-language drift fails the build.
- NHL ingestion goes through `draft_oracle.ingest.nhl_api.NHLApiClient` — the ONLY place
  NHL URLs may appear (api-web base `.../v1`, stats-rest base `.../stats/rest/en`). Add
  typed adapters there; pydantic models use `ConfigDict(extra="ignore",
  populate_by_name=True)` + `Field(alias="camelCase")`. Test with an injected
  `httpx.Client(transport=httpx.MockTransport(...))`, `delay=0.0`, `retry_backoff=0.0`,
  `sleep=noop`, temp cache dir — no network, no real sleep. MockTransport route keys use
  the FULL request path incl. `/stats/rest/en`. Raw JSON caches to gitignored
  `data/raw/nhl-api/`; a cache hit skips the network entirely.
- Normalized Parquet tables live in gitignored `ml/data/normalized/` via
  `draft_oracle.ingest.normalize`. Position collapse is `map_position` (C/L/R->F, D->D,
  G/other->None => dropped from skater pool). `team_games.team_abbrev` is DERIVED (not in
  the source) by pairing a game's two mirror rows — the archive names own-team by id but
  opponent by abbrev. Real archive normalizes to 522,185 skater_games / 29,016 team_games
  / 173 series / 2,156 players / 34 teams — skater/team counts match PROVENANCE exactly.
  Ingestion is idempotent via `_manifest.json` (source-size signature; unchanged => skip)
  and every table dedups on its natural key. `oracle normalize [--force]` and
  `oracle snapshot [--list]` are the CLI entry points; snapshots freeze a dated copy under
  `data/normalized/snapshots/<id>/`.
- Betting odds go through `draft_oracle.ingest.odds`. De-vig: two-sided prices
  (SBR Close) use `devig_proportional` (each `1/decimal` divided by the overround
  sum -> sums to 1); favorite-only prices (Kaggle/ESPN) use `devig_favorite_only`
  with a documented `STANDARD_OVERROUND=1.045` and NEVER fabricate an underdog
  American price (only probabilities). Team names resolve via `resolve_team_id`
  (NHL_TEAMS + explicit city/typo aliases; the rsplit "city" mishandles two-word
  nicknames like Maple Leafs/Red Wings/Blue Jackets -> every franchise city is
  aliased explicitly). Playoffs tagged by real per-season windows
  (`_PLAYOFF_WINDOWS`), NOT April-June: 2020 bubble = Aug-Sep, 2021 = May-Jul.
  SBR MMDD->year: months >=8 belong to the earlier year EXCEPT 2019-20 whose
  Aug-Sep bubble belongs to the ending year 2020 (special-cased in
  `_reconstruct_date`). Consolidation matches sources on (season,away,home) with
  a +/-1 day tolerance (Kaggle/ESPN dates are UTC, one day ahead of SBR local),
  at most one row per source per cluster so adjacent same-matchup games never
  merge; prefer SBR Close. `oracle odds [--no-odds]` builds odds.parquet +
  odds_by_source.parquet. `openpyxl` was added to deps for the SBR .xlsx.
- Live odds clients (`OddsApiClient` for The Odds API `icehockey_nhl`;
  `EspnGameOddsClient` for ESPN `summary`/pickcenter) mirror NHLApiClient's
  cache + retry + injectable `httpx.Client`/`sleep`; keys from env (`ODDS_API_KEY`),
  never committed. Test with `httpx.MockTransport`, `delay=0.0`, no network.
- Windows console is cp1252: NEVER print non-ASCII (`->` arrows, em-dashes) in
  `typer.echo` output — it crashes with UnicodeEncodeError. Use ASCII.
- Typer options must use `Annotated[T, typer.Option(...)] = default` (NOT
  `x: T = typer.Option(default, ...)`) or ruff B008 fails on function-call-in-defaults.
