## Codebase Patterns
- Use `npx nx sync` after adding new packages — it updates TypeScript project references automatically
- Mantine SegmentedControl renders hidden `<input type="radio">` — use `locator('label:has-text("...")')` to click, not `getByRole('radio')`
- DraftPage hooks: all useMemo/useEffect calls must appear BEFORE early returns to avoid React hooks order violations
- DraftPage uses `currentSeason = '20242025'` hardcoded — mock data season doesn't matter since PostgREST mocks ignore query params
- rspack config needs DefinePlugin for `import.meta.env.VITE_*` variables — NxAppRspackPlugin only handles `NX_PUBLIC_*`
- Supabase OTP endpoint is called with `?redirect_to=` query param — use glob `**` suffix in route interceptors
- Page objects use `getByRole`, `getByText`, `getByPlaceholder` — no `data-testid` attributes exist in app
- Import page objects from `../page-objects` — all take a Playwright `Page` in constructor
- App uses Mantine UI — selectors target headings, buttons, tables, badges by role/text
- Playwright config uses `webServer.cwd: '../..'` to reach the monorepo root for `nx serve`
- E2E env vars: `VITE_SUPABASE_URL=http://localhost:54321` and `VITE_SUPABASE_ANON_KEY=mock-anon-key`
- Yarn workspaces auto-resolve `@playwright/test` from root — no need to install separately in e2e
- Auth fixtures: import `{ test, expect }` from `../fixtures/auth.fixture` and use `authenticatedPage`/`unauthenticatedPage`
- Supabase JS stores session in localStorage under `sb-{hostname}-auth-token` — seed via `page.addInitScript()`
- Import `supabasePage` fixture from `../fixtures/supabase-mock.fixture` — use `supabasePage` fixture or `setupSupabaseMocks(page, overrides)` directly
- PostgREST `.single()` uses `Accept: application/vnd.pgrst.object+json` header — mock handlers should check for it
- Use `mockTableList(data)`, `mockTableData(list, single)`, `mockTableError(status, msg)` helpers for route overrides
- E2E tsconfig needs `rootDir: "../.."` and types source in `include` to import from `@sportsnot/types`
- Data factories: import from `../fixtures/data-factories` — all accept `Partial<T>` overrides
- PostgREST join queries (e.g., `leagues` with `league_members!inner(...)`) return nested arrays — mock data must include the joined table as an array property
- Mantine CopyButton + Tooltip wraps ActionIcon — select copy button by emoji content (e.g., `📋`), not tooltip label
- LeagueDashboardPage `.single()` join query includes nested `users` object inside `league_members` — mock must match shape
- Commissioner status: `league.commissioner_id === user.id` — use `mockUser.id` as commissioner_id for commissioner tests
- JoinLeaguePage lookup uses `.single()` with `league_members(id)` join — mock needs nested `league_members` array with `{ id }` entries only
- Settings page query key is `league-settings` — separate invalidation from dashboard `league` key
- Settings page `canModify = isCommissioner && league.status === 'setup'` — controls are disabled outside setup phase
- Draft lobby queries leagues with `league_members(id, user_id, team_name, users(display_name))` join — mock must include nested `users` object
- Draft lobby uses `current_round + 1` as nextRound — set `current_round: 0` for Round 1 display
- "Test User" display_name appears in both nav bar and member list — scope assertions to `getByRole('list')` to avoid strict mode violations
- Use `{ exact: true }` for number text assertions (e.g., `getByText('3', { exact: true })`) to avoid matching substrings like `33`
- Compare tray has `data-testid="compare-tray"` — scope text assertions to avoid matching both table rows and compare tray
