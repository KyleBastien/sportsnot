## Codebase Patterns
- Context pattern: Create in `packages/web/src/app/context/`, export Provider + useXxxContext hook
- Provider wiring: Add providers in `packages/web/src/main.tsx`, nest inside AuthProvider if auth-dependent
- Types: Shared types in `packages/types/src/lib/types.ts` and `nhl.ts`, exported via `@sportsnot/types`
- Monorepo: Uses Nx with Yarn, packages at `packages/{web,ui,supabase,types,utils,nhl-api}`
- UI: Uses Mantine component library
- Typecheck: `npx tsc -p packages/web/tsconfig.app.json --noEmit` (nx typecheck has pre-existing config issue)
- Lint: ESLint has pre-existing false positives for `no-unused-vars` on TS interface param names (same as AuthContext)
- Lint workaround: Use `// eslint-disable-line no-unused-vars` for interface callback params
- Floating UI: Use Mantine's `Affix` + `Transition` for fixed-position floating components
- App-wide components: Render inside `AppShell` in `app.tsx` (after `AppShell.Main`)
- Responsive: `@mantine/hooks` provides `useMediaQuery`; Mantine Modal supports `fullScreen` prop
- ComparePlayer.stats: `Record<string, number>` - use key `fantasyPoints` for fantasy points display
- Icons: No icon library installed; use unicode/emoji characters (✓, ⚖, ✕) in ActionIcon children
- UI package independence: `@sportsnot/ui` must not import from `@sportsnot/web`; use callback props for context-dependent behavior
- UI package lint: `nx lint ui` not configured; use `npx eslint <file>` directly
