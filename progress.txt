## Codebase Patterns
- Use `@rstest/core` (describe/it/expect) for unit tests, NOT vitest or jest
- Run `npx eslint --fix` on new/changed files to fix CRLF line endings on Windows
- When adding mock hooks, always add a corresponding noop export in `packages/web/src/mock/stubs/mock-noop.ts`
- The `NormalModuleReplacementPlugin` in rspack.config.js replaces all `mock/hooks/` imports with `mock-noop.ts` in production — missing exports will crash the entire app
- Pure validation logic should be extracted from components into separate modules (e.g., `profileValidation.ts`) for easy unit testing
- The `ProfileUpdateClient` interface pattern allows testing update logic with mock clients without React component rendering
- E2e tests (79/87) fail on main branch — pre-existing issue unrelated to profile feature
- New env vars used via `import.meta.env` must be declared in `packages/web/src/env.d.ts`
