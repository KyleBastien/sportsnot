## Codebase Patterns
- Use `@rstest/core` (describe/it/expect) for unit tests, NOT vitest or jest
- Run `npx eslint --fix` on new/changed files to fix CRLF line endings on Windows
- When adding mock hooks, always add a corresponding noop export in `packages/web/src/mock/stubs/mock-noop.ts`
- The `NormalModuleReplacementPlugin` in rspack.config.js replaces all `mock/hooks/` imports with `mock-noop.ts` in production — missing exports will crash the entire app
- Pure validation logic should be extracted from components into separate modules (e.g., `profileValidation.ts`) for easy unit testing
- The `ProfileUpdateClient` interface pattern allows testing update logic with mock clients without React component rendering
- E2e tests (79/87) fail on main branch — pre-existing issue unrelated to profile feature
- New env vars used via `import.meta.env` must be declared in `packages/web/src/env.d.ts`
- E2E auth tests that reference button text ("Send Magic Link") must be updated when the default login method changes (OTP checkbox is now checked by default)
- Extract pure display logic (button text, subtitle text) from React components into utility modules for easy unit testing
- Mantine PinInput is imported from `@mantine/core` and supports `length`, `type="number"`, `value`, and `onChange` props
- Auth callback E2E test and sign-out E2E test are pre-existing failures (not caused by OTP changes)
- The useEffect for setInterval-based timers needs the cooldown value in the dependency array so it starts/stops correctly
- Use functional updater `(prev) => prev - 1` in setState inside setInterval to avoid stale closures
- E2E auth fixture route mocks MUST use glob patterns (`**/auth/v1/...`) NOT hardcoded `http://localhost:54321` — the app uses the real Supabase URL from .env, not localhost
- E2E fixture `eslint.config.mjs` must include `globals.node` for `fixtures/**/*.ts` (not just `*.config.ts`)
- Playwright routes registered later take precedence over earlier ones — use this to override fixture mocks in individual tests
- LoginPage needs a `useEffect` that redirects to `/` when `user` becomes non-null (OTP verify doesn't auto-redirect like magic link callback)
